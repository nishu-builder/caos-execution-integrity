Rerun the saved work

The repository includes Git objects for 32 worker jobs: their tool code, input files, worker image, and recorded results. Send them to your own CAOS runner and compare what it returns. See the reproduction guide for setup.

python3 reproduce.py run --server http://localhost:9090

The command uses fresh cache keys by default. The guide also shows how to fetch the objects with Git and submit the saved requests directly.
